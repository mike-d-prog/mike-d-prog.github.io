HW Dental: Reaching Medicaid & Spanish-Speaking Patients

Key business research question: how well is the clinic — overall and by branch — reaching Medicaid and Spanish-speaking populations, and how might it grow in ways that attract more of both?

Working with HW Dental's patient dataset, combined with external population and school-district data, to turn that question into a set of concrete, branch-level recommendations. Sub-questions drafted with input from Claude, refined against what the data can actually support:

  1. What's the current breakdown and zip-code distribution of Medicaid and/or Spanish-speaking patients across branches, and how has it shifted over the dataset's timeline?
  2. How does each branch's current Medicaid and/or Spanish-speaking share compare to the population nearby, and which branches are over- or under-performing relative to that benchmark?
  3. Which schools or school districts have characteristics that would make them attractive partners for the clinic?
  4. Can Medicaid status be predicted from patient and referral data, and which referral channels are most associated with reaching Medicaid patients?
Census data pull — R 
# Install packages if you don't have them yet 
library(tidycensus) 
library(dplyr) 

# 1. Set your Census API key 
# install = TRUE saves it so you don't have to re-enter it every session 
census_api_key("INSERT YOUR KEY HERE", install = TRUE, overwrite = TRUE)
 
# 2. Identify the tables and variables that you want to pull data from 
acs_vars <- c(
  medicaid_pct   = "S2701_C05_001",  # with Medicaid/means-tested                    
  hispanic_pct   = "DP05_0071P",
  spanish_ell_pct = "S1601_C02_004",  # Percent, Population 5+, Spanish
  poverty_pct    = "S1701_C03_001"
) 

oh_data <- get_acs( geography = "zcta",  # or "tract", "block group", "state", etc. 
                    variables = acs_vars,
                    year = 2023, # most recent 5-year ACS 
                    survey = "acs5" # or "acs1" for 1-year estimates
) 

# 3. Ohio ZIP codes generally start with 43, 44, or 45 
oh_filtered <- oh_data %>% filter(substr(GEOID, 1, 2) %in% c("43", "44", "45"))

# 4. Look at it to be sure the data seems correct 
head(oh_filtered) 
nrow(oh_filtered)

# 5. Save to CSV
write.csv(oh_filtered, "ohio_acs.csv", row.names = FALSE)
